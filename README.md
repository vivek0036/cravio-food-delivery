# Cravio – Food Delivery

A modern food delivery web application inspired by Swiggy.

## Features

- Created project using Vite
- Configured Tailwind CSS v4
- Created Header component
- Added restaurant logo and navigation links
- Created Body component
- Added Shimmer UI for restaurant listing
- Created reusable RestaurantCard component
- Displayed restaurant listings dynamically using JSON data
- Added restaurant images and details to cards
- Added 16 restaurants with individual JSON data
- Created RestaurantMenu component
- Implemented dynamic restaurant menu loading using URL parameters
- Displayed restaurant categories and menu items dynamically
- Created reusable RestaurantCategory component for menu categories
- Created reusable ItemList component to display food items
- Displayed restaurant information including rating, total ratings, cost for two and delivery time

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- React Router DOM
